# Bhasha Bridge 🚀

Bhasha Bridge is a Python-based translation engine engineered to seamlessly break down communication barriers across India's diverse linguistic landscape. The application leverages advanced neural translation APIs to map contextual translations dynamically between English and multiple major regional languages.

## 🌟 Key Features
- **Interactive Multi-Language Pipeline:** Translates input text into multiple languages sequentially without resetting the environment.
- **Robust Virtual Environment Configuration:** Completely isolated setup using modular practices.
- **Dynamic Language Support:** Features direct integration mappings for:
  - Hindi 🇮🇳
  - Telugu 🌾
  - Tamil 📜
  - Kannada 🏛️
  - Bengali 🎨

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Core Translation Engine:** Googletrans Neural API Architecture
- **Environment Management:** Python Virtual Environments (`.venv`)

## 🚀 How to Run Locally
1. Clone the repository to your machine.
2. Initialize and activate your local virtual environment.
3. Install dependencies:
   ```bash
   pip install googletrans==4.0.0-rc1
   ```
4. Run the interactive engine script:
   ```bash
   python main.py
   ```
